📊 Power BI Dashboard Layout
1. Executive Overview Page

KPIs (cards):

Total Revenue (YTD vs Target)

Pipeline Conversion Rate

Average Revenue per Sale

Top Performing Branch

Visuals:

Trend line: Revenue over time (monthly)

Funnel chart: Leads → Opportunities → Closed Deals

Filters:

Date range

Region

Branch

2. Sales Rep Performance Page

KPIs:

Revenue per Rep

Units Sold per Rep

Conversion Rate per Rep

Visuals:

Bar chart: Revenue by Sales Rep

Scatter plot: Revenue vs Conversion Rate

Filters:

Branch

Product category

3. Branch Comparison Page

KPIs:

Total Revenue per Branch

Average Deal Size

Pipeline Health

Visuals:

Heatmap: Branch performance by KPI

Line chart: Branch revenue trends

Filters:

Region

Time period

4. Product Analysis Page

KPIs:

Revenue per Product

Units Sold per Product

Profit Margin (if available)

Visuals:

Pareto chart: Top 20% products driving 80% revenue

Bar chart: Units sold by product category

Filters:

Product category

Branch

5. Alerts & Targets Page

KPIs:

KPI Targets vs Actuals

Alerts triggered (e.g., pipeline conversion < 20%)

Visuals:

Gauge chart: KPI target achievement

Table: Alerts log with timestamps

Filters:

KPI type

Branch
